# Kairo Gallery (Projeto de Teste Final v1)

Aplicação de aceitação que exercita todos os componentes da v1 usando **exclusivamente APIs públicas** do Kairo.

## 12 Categorias Cobertas
1. Layout (`Column`, `Row`, `Box`, `Stack`, `Scroll`)
2. Texto e ações (`Text`, `Button`)
3. Input (`Input`, `TextArea`)
4. Seleção (`Checkbox`, `Switch`, `Select`)
5. Media e superfície (`Image`, `Card`, `Divider`)
6. Feedback (`Progress`)
7. Form (`Form`, `FormField`, validação e submissão)
8. Listas (`List` com template, `StableKey` e mutações em 10 000 itens)
9. Navegação (`Router`, `Route`, `push`/`pop`/`replace`/back)
10. Async (`FutureState`: loading, erro, sucesso, cancelamento)
11. Temas e estados (claro/escuro, `pressed`, `focused`, `disabled`, `selected`, `checked`, `error`)
12. Stress (aninhamento profundo, listas grandes, texto longo)
